Project 06

ME190 Hybrid Hand-Actuated Espresso Machine

Senior design project focused on an espresso machine that pulls a double shot through a 58 mm portafilter at industry-standard pressure using a mechanical advantage system and controlled water heating.

  • Contributed to electrical fundamentals and system planning for heating, pumping, logic power, and future automation features.
  • The design uses a worm gear and linkage system to generate high piston force with low user input.
  • Project documentation includes full assembly drawings, exploded views, electrical/plumbing diagrams, test plans, and mechanical analysis.
