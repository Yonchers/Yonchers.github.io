# Joseph Dwyer Engineering Portfolio Website

This is a static public portfolio site generated for GitHub Pages, Cloudflare Pages, Netlify, or any simple web host.

## What is included

- `index.html` — one-page portfolio website
- `style.css` — site styling
- `script.js` — mobile menu and image lightbox
- `assets/images/` — optimized portfolio images
- `assets/downloads/` — resume and portfolio PDFs
- `assets/video/` — optional local project videos

## Safe public hosting recommendation

Use GitHub Pages or Cloudflare Pages. Do not expose a home server, AI server, 3D printer controls, Tailscale devices, SSH, databases, or private services to the public internet for a simple portfolio site.

## GitHub Pages quick setup

1. Create a GitHub repository named `yourusername.github.io` or a normal repo such as `portfolio`.
2. Upload the contents of this folder, not the outer zip itself.
3. Go to Repository Settings -> Pages.
4. Choose `Deploy from a branch`.
5. Select `main` and `/root`.
6. Save and wait for GitHub to publish the URL.

## Editing notes

- Replace PDFs inside `assets/downloads/` when your resume or portfolio changes.
- Add new project images to `assets/images/`.
- Update project wording directly in `index.html`.
- The site intentionally excludes raw transcripts, student IDs, phone number, and private infrastructure details.
