# Joseph Dwyer Engineering Portfolio Website

This is a static website package intended for GitHub Pages, Cloudflare Pages, Netlify, or any plain web host.

## Files

- `index.html` - main site
- `style.css` - blue/white blueprint-style theme inspired by the provided website screenshots
- `script.js` - mobile menu and image lightbox
- `assets/images/` - optimized project photos
- `assets/downloads/` - resume and portfolio PDF downloads
- `assets/reference/` - uploaded website screenshot references used for theme direction

## GitHub Pages deployment

1. Create a new public repository on GitHub.
2. Upload all files from this folder into the repository root.
3. Open Settings -> Pages.
4. Set Source to `Deploy from a branch`.
5. Choose the `main` branch and `/root` folder.
6. Save. GitHub will publish the site after a short build.

## Privacy note

The visible site keeps local network and home server access details out of the copy. The resume PDF still contains the contact information present in the uploaded source resume.
