Active · Private project

Print Orchestrator

AI-automation frontend and mixed-fleet control layer for PrusaLink and Moonraker/Klipper machines. The system brings jobs, cameras, temperatures, power, files, part detection, recovery controls, and machine-specific state into one API-backed interface. Prototype Hermes workflows connect OpenSCAD generation, a modified OrcaSlicer CLI, preflight checks, API dispatch, modified Obico failure warnings, Discord, and Kasa smart-plug control.

  • Part-on-bed start interlock
  • Kasa power telemetry
  • AI vision warnings
  • Prompt-to-print R&D
